# Research Plan — sidon-ulam-control

## Who I am

Orchestrator, phase 3 (decision made, proposal written). This is an open-ended explore run.

## Chosen question

Do Sidon-set constructions (sparse integer sequences in which every pairwise sum is unique, *not* generated by the Ulam recursion) exhibit deep Fourier dips comparable to the hidden-α signal in the Ulam sequence?  If so, the Ulam phenomenon is not specific to the Ulam construction; if not, the specificity claim survives its strongest possible adversarial test.

## Why this / why now

The Ulam-hidden-periodicity study found a ~−194σ Fourier dip that no random density-matched sparse sequence reproduced.  Its refuter returned one "NOT TESTED" verdict: Sidon sets — the strongest possible "hand-tuned sparse sequence" control.  Closing this gap is the single most impactful follow-up from the existing portfolio, because the Sidon control directly attacks whether the Ulam construction *means* anything or is just one of many sparse sequences with weird Fourier-side structure.

## Rejected alternatives
- **Rule 22 substitution-system proof (ECA)** — high-quality, but ECA already has 2 completed studies; we deliberately weight away from over-mined domains.
- **Gutenberg–Richter b-value (USGS earthquakes)** — new domain, good diversity, but lower stake: b-value fitting is a well-understood empirical exercise with a predictable positive outcome.
- **Ulam-type (a,b) sweep** — cheap extension, low novelty; adds cases but doesn't resolve an open gap.
- **LLP/CF closed-form probe for α** — likely null (nothing found), and a negative symbolic-search result is hard to interpret.

## What we will vary / measure

1. **Sidon constructions** (≥3 distinct families):
   - Greedy Sidon set (Bose–Chowla finite-field based, or greedy algorithm).
   - Bose construction (q a prime power, elements a_i = i·q + (i² mod q)).
   - Random-thinned Sidon: start with a random sparse sequence, greedily remove collisions to enforce B_2 uniqueness.
2. **N**: 10,000 and 30,000 terms (same regime as the Ulam random-sequence control).
3. **Measure**: deepest Fourier dip `min_{x∈[0.05,π]} f_N(x)/N`, same search protocol as the Ulam study (coarse grid + `FindMinimum`).
4. **Controls**:
   - Ulam(1,2) at N=30,000 for direct comparison.
   - 20 fresh random density-matched sequences (re-run of the prior control, smaller n, for calibration).
5. **Compute budget**: ≤10 minutes per construction × 3 constructions + controls ≈ 40 minutes total in-kernel time. Chunked so no single evaluation exceeds 60 s.

## What counts as "interesting"

- If any Sidon construction dips below −0.1 (i.e., within an order of magnitude of Ulam's −0.8): **major** — the specificity claim is qualitatively weakened.
- If all Sidon constructions behave like random sequences (dip magnitude < 0.02): the specificity claim survives its hardest test.
- If a Sidon construction shows an *intermediate* dip (0.02–0.1): opens a ""structured sparse sequences"" angle worth probing further.
